# Intake (fictional, unclassified)

We need AI in the operations center at Northbridge Logistics.

The staff currently spends most of a shift stitching site briefs together from shared drives and chat threads. When a warehouse WAN link drops, there is no assistant at all. Finance and site operations should not see the same document set — access is role-based — and nobody should be pasting personal or sensitive fields straight into a model.

If this thing can also share a brief with an external carrier partner, a human has to approve that first. It has to keep working inside our own network with no public internet path.

We do not want a company-wide rollout. We want a four-week pilot we can actually measure.

This request is invented for a software demo. Northbridge Logistics is a fictional organization. All data used with it must stay fictional and unclassified.
