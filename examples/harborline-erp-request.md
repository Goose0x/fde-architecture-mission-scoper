# Intake (fictional, unclassified)

The operations team at Harborline Retail keeps asking for "AI on the ERP."

Today an analyst looks up a ticket or requisition in a thick client, then pastes the answer into a chat tool, then types an update back into the ERP. Leadership wants the assistant to do that for them. The system of record is a legacy SOAP API that we are not going to replace this quarter.

They cannot have the model calling Delete or posting unlogged writes. If something is going to change a record, we want a dry-run first and a person to confirm it. We also need an audit trail IT can read.

This is a made-up request for a software demo. Harborline Retail is a fictional organization. Do not connect to a real SAP, Oracle, or other production system. Use fictional records only.
